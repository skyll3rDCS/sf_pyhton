# Анализ резюме с HeadHunter

## Описание проекта
Разведывательный анализ данных резюме с hh.ru для выявления факторов, влияющих на заработную плату соискателей.

## Данные
Исходный датасеты `dst-3.0_16_1_hh_database.csv` и `ExchangeRates.csv` доступны по ссылке: https://drive.google.com/drive/folders/1uMQTk2iY2LMExMUwGPOeFjRbGN6mAU4D?usp=drive_link

**Для запуска анализа:**
1. Скачайте файлы по ссылке выше
2. Положить их в папку `data/` 
3. Запустите ноутбук `Python_для_анализа_данных__Итоговый__проект_aga.ipynb`

## Ключевые этапы анализа
1. Предобработка данных
2. Анализ распределений признаков
3. Исследование зависимостей заработной платы
4. Визуализация результатов

## Визуализации
Все графики реализованные с помощью plotly сохранены в формате HTML в папке `graphs/`.  
Для просмотра откройте файлы в браузере.

## Используемые библиотеки
- pandas
- numpy  
- matplotlib
- seaborn
- plotly
- scipy

## Результаты
В ходе анализа выявлены ключевые факторы, влияющие на уровень заработной платы:
- Уровень образования
- Город проживания
- Опыт работы
- Готовность к командировкам и переезду
